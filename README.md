# Headless CHIP-8 Virtual Machine

**A low-level systems engineering project demonstrating CPU architecture and hardware emulation.**

## 👨‍💻 Developer Context

Built to bridge the gap between bare-metal hardware and high-level software, applying foundational concepts from Digital Logic Design, Assembly, and Operating Systems into a functional C++ architecture. This emulator serves as a capstone systems software project, succeeding the development of a custom UNIX command-line shell.

## 🛠️ Technical Stack & Competencies

- **Language:** C++
- **Core Skills:** Computer Architecture, Bitwise Manipulation, Instruction Set Architecture (ISA) implementation, Memory Mapping, Windows API.

## ⚙️ Architectural Highlights

- **Core CPU Pipeline:** Engineered a complete fetch-decode-execute cycle to emulate legacy hardware instructions, decoding hex opcodes into system actions.
- **Hardware Modeling:** Programmed virtual CPU components from scratch, including 4KB of addressable RAM, 16-bit program counters, a call stack, and a custom Arithmetic Logic Unit (ALU) to process standard bitwise math operations.
- **Headless Rendering Engine:** Developed a zero-dependency ASCII rendering system, interfacing directly with the Windows API to process UTF-8 byte streams and draw a 64x32 pixel buffer directly to the terminal without external GUI libraries.
- **Memory Safety:** Implemented robust bit-masking (`& 0xFF`, `& 0x0FFF`) to enforce 8-bit register boundaries, preventing integer overflow and segmentation faults during memory read/write cycles.

## 🚀 Execution & Usage

The emulator operates entirely within the terminal using standard I/O and Windows Virtual Terminal Processing.
